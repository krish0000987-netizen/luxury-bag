# LUXURY BAGS — Jaipur, Rajasthan
### Ultra-Premium Women's Luxury Handbag & Bridal Minaudière E-Commerce Platform

Inspired by the royal courts of Rajasthan and situated **Near Hawa Mahal, Jaipur**, **LUXURY BAGS** delivers a ₹50-Lakh luxury aesthetic tailored for high-fashion connoisseurs, royal brides, and evening galas.

---

## ✦ Key Highlights

- **Visual Direction**: Built around our flagship kundan, crystal, and pearl minaudière clutch with multi-angle views and bespoke companion pieces.
- **10 Dedicated Pages**:
  1. `Home` — 3-second auto-advancing cinematic hero slideshow, featured collections, flagship showcase, best sellers, bridal edit, and lifestyle galleries.
  2. `Shop All` — Full editorial catalog with multi-criteria filtering (Category, Occasion, Material, Price) and sorting.
  3. `New Arrivals` — Seasonal drops with luxury badges and editorial intermezzos.
  4. `Bridal & Wedding Collection` — "For the Bride Who Deserves the Extraordinary" with interactive "Complete Your Bridal Look".
  5. `Clutch Collection` — Editorial minaudières, box clutches, and crystal evening pieces.
  6. `Luxury Handbags` — Structured bags, pearl top-handles, and royal velvet zardozi potlis.
  7. `About Us` — "Born in Jaipur. Designed for the Extraordinary." Authentic Rajputana heritage copy.
  8. `Jaipur Craftsmanship` — 6-step interactive visual journey from archival inspiration to final keepsake chest.
  9. `Lookbook / Gallery` — High-fashion magazine editorial layout with "Shop the Look" triggers.
  10. `Contact & Store` — Near Hawa Mahal, Jaipur, Rajasthan; Phone & WhatsApp: `+91 96029 57926`.

- **WhatsApp E-Commerce Engine**:
  - Direct 1-click WhatsApp order buttons for every product with pre-filled SKU, name, price, and quantity.
  - Multi-item slide-out cart order generator compiling itemized invoice with delivery address fields.
  - Floating WhatsApp concierge with contextual product awareness.

- **Design System**:
  - Palette: Champagne silk, warm ivory, antique gold (`#C5A059`, `#D4AF37`), and rich royal charcoal.
  - Typography: *Cormorant Garamond*, *Cinzel*, and *Plus Jakarta Sans*.
  - Fully responsive on mobile, tablet, and desktop with a sticky mobile bottom navigation bar.

## ✦ Tech Stack

- **Core**: Vanilla JavaScript (ES6+ Modules) & Vanilla CSS
- **Bundler**: Vite
- **Typography**: Google Fonts (*Cormorant Garamond*, *Cinzel*, *Plus Jakarta Sans*, *Montserrat*)

---

## ✦ Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
